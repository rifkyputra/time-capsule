# Lessons — What Each Era Taught Me

## 2015–2016: The Beginning

**`hello-world`** — Every dev starts here. The GitHub tradition.

**Blogger templates** (`matstyle-btemplate`, `ghosty-btemplate`) — Got into code by tweaking blog themes. HTML/CSS by trial and error. The gateway drug.

> **Lesson:** Ship something visible. A live blog theme beats a perfect local project no one sees.

---

## 2018: JavaScript Awakening

**`kapurjs`** — First real boilerplate. ES7, front-end tooling, build pipelines. Started thinking like an engineer not a tinkerer.

**`portfolio-rifky`** — First portfolio. Learned that a dev without a portfolio is invisible.

> **Lesson:** Tooling matters. A boilerplate you understand is worth 10 you copied. Own your setup.

---

## 2019: Full-Stack Curiosity

Docker (`strapi-docker`), static sites (`academic-kickstart`), Jekyll themes, multiple HTML projects — reaching beyond the browser into servers and deployment.

> **Lesson:** The browser is half the picture. Understanding what runs the server opens every door.

---

## 2020: Flutter Arrives

**`Ajarku`** — First real Flutter app. Social media for learning. The spark.

**`flutterSM`**, **`background-fetch-test-case`** — Mobile thinking: background tasks, platform APIs, real device constraints.

> **Lesson:** Flutter changes the game. One codebase, multiple platforms. Mobile dev without the platform wars.

---

## 2021: The Flutter Deep-Dive

13 repos, almost all Dart/Flutter. This was the year Flutter became home:

- **Architecture**: `flutter-modularite` — attempted clean modular Flutter
- **Backend in Dart**: `try-shelf`, `shelf-article-api` — HTTP servers in Dart
- **Pushing boundaries**: `http-server-flutter-poc` — running an HTTP server _inside_ Flutter
- **ML/AI**: `face-recognition` — Firebase ML Kit + Flutter
- **CLI**: `cli-hitung` — Dart for command-line tools
- **Rust enters**: `rust-latihan` — first steps into systems programming

> **Lesson:** Go deep on one stack before spreading thin. A year of Flutter taught more than 5 years of hopping. Also: Dart on the server is underrated.

---

## 2022: The Everything Explosion

20 repos. The peak exploration year — and the most "pe'a" (read: gloriously cringe):

- **gRPC**: `grpc-chat-flutter-dart` — real-time chat over gRPC
- **Game dev**: Unity, Unreal Engine GAS, C++ — tested the waters
- **Go**: `golang-latihan`, `go-base` — Go REST APIs with JWT + Postgres
- **Rust web**: `actix-web-examples` — Rust HTTP frameworks
- **Riverpod**: `riverpod-example`, `commodity-price-riverpod` — Flutter state management mastery
- **Performance**: `flutter_smooth` — chasing 60 FPS at all costs
- **Community**: `api-wilayah-indonesia` — static API for Indonesian administrative regions
- **Toolbelt**: `cantlivewithout` — curated dev resources
- **JKT48 era**: A certain birthday app that shall not be named

> **Lesson:** Explore everything while the fire is hot. Not every experiment needs to become a product. The breadth builds intuition; depth comes later. Also: no regrets — even the "pe'a" repos are proof you were building.

---

## The Arc

```
2015-16 → Discovery (blog themes, HTML)
2018    → Engineering (boilerplates, tooling)
2019    → Full-stack (Docker, servers, deployment)
2020    → Flutter ignition
2021    → Flutter mastery (architecture, backend, ML)
2022    → Exploration (gRPC, Go, Rust, Unity, gamedev, performance)
2023+   → Consolidation (fewer repos, more depth, real products)
```

The pattern is clear: **wide exploration → deep consolidation**. The 2023+ era (Devlyn, Indokorpus, Micromeet, Kuadrat, Gnomix, Postlab) wouldn't exist without every experiment in this capsule.
